Olá! Sou técnica em Desenvolvimento de Sistemas e atualmente curso Tecnólogo em Ciência de Dados. Sou fascinada pelo ecossistema de dados e inteligência artificial, dedicando meus estudos e projetos à engenharia de dados, com construção de pipelines de dados eficientes, análise preditiva e desenvolvimento de soluções baseadas em IA (como Machine Learning, Deep Learning, NLP e Agentes de IA). 

Atualmente, busco aprimorar minhas habilidades em engenharia de dados, computação em nuvem (AWS/Azure) e MLOps para criar arquiteturas de dados robustas e modelos escaláveis.
